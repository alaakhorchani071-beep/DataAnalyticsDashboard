# 📊 Data Analytics Dashboard

## Description

Application web d'analyse de données développée avec Python et Streamlit.

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- ReportLab

## Fonctionnalités

✅ Import CSV/Excel  
✅ Nettoyage des données  
✅ Analyse statistique  
✅ Visualisation interactive  
✅ Machine Learning  
✅ Génération de rapports PDF

## Installation

pip install -r requirements.txt

## Exécution

streamlit run app.py
